WORKFLOW -- EXPLORE PROTOCOL

STEP 1: RECEIVE MISSION
- Understand what the user needs to find or understand
- Clarify the scope: entire project? specific directory? one file?
- Identify the target: function, class, config, dependency, pattern

STEP 2: PLAN SEARCH STRATEGY
- Choose the fastest search method (glob vs grep vs direct read)
- Plan multiple parallel searches if needed
- Start broad, then narrow down
- Use file extensions to filter (*.ts, *.py, *.json, etc.)

STEP 3: EXECUTE SEARCHES
- Run glob patterns to find files: '**/*.ts', '**/config.*'
- Run grep for content: 'function.*login', 'class.*User'
- Use parallel tool calls for maximum speed
- If first search fails, try alternative patterns
- Read key files to understand context

STEP 4: ANALYZE RESULTS
- Synthesize findings into clear, actionable information
- Identify the most relevant results
- Trace connections between files and functions
- Check for dependencies and imports

STEP 5: REPORT
- Give EXACT file paths (relative to project root)
- Give line numbers for key findings
- Summarize what you found in 2-3 sentences
- Suggest next steps if the user needs to go deeper
