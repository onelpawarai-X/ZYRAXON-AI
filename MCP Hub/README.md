# MCP Hub

ZYRAXON-এর জন্য একটা "Connect" প্যানেল। হোম পেজে একটা বাটন, ক্লিক করলে
সব অ্যাপের কার্ড, যেকোনো কার্ডে ক্লিক করলে লগইন — আর টুল চলে যায় এজেন্টের কাছে।

**সব কোড এই ফোল্ডারে।** বাইরের কোনো ফাইল বদলানো হয় না (দেখুন
`HOST-INTEGRATION.md`)।

## কতগুলো অ্যাপ কানেক্ট করা যায়

| স্তর | সংখ্যা |
|---|---|
| কিউরেটেড ক্যাটালগ (হাতে বাছা) | **১৭** |
| অফিসিয়াল MCP রেজিস্ট্রি (লোকাল ক্যাশ) | **৯,৫৮০** |
| রেজিস্ট্রি (লাইভ, ক্যাশের বাইরে) | **১৮,০০০+** এবং বাড়ছে |

রেজিস্ট্রির ৮,৫১৭টি সার্ভার **হোস্টেড** — অর্থাৎ একটা URL দিয়েই কানেক্ট করা যায়,
আপনার মেশিনে কিছু ইনস্টল করতে হয় না।

## কোন অ্যাপে আপনাকে কিছু দিতে হবে না

লাইভ যাচাই করা (MCP স্পেকের `WWW-Authenticate` + `oauth-authorization-server`):

| অ্যাপ | Client ID লাগবে? |
|---|---|
| Notion | ❌ না |
| Linear | ❌ না |
| Atlassian (Jira) | ❌ না |
| Sentry | ❌ না |
| Stripe | ❌ না |
| Cloudflare | ❌ না |
| Figma | ❌ না |
| GitHub | ✅ হ্যাঁ (একবার) — GitHub-এর AS-এ DCR নেই |

## ফোল্ডার গঠন

```
MCP Hub/
  plugin.ts               হোস্ট এন্ট্রি — শুধু এটাই ZYRAXON ডাকে
  catalog/
    seed.ts               হাতে বাছা ১৭টি অ্যাপ
    registry-cache.json   ৯,৫৮০টি রেজিস্ট্রি সার্ভার (লোকাল ক্যাশ)
  lib/
    registry.ts           লাইভ রেজিস্ট্রি ক্লায়েন্ট + zero-setup শনাক্ত
    connect.ts            কানেক্ট ফ্লো, টুল হ্যান্ডঅফ, স্টেট
  ui/
    mcp-hub-panel.tsx     প্যানেল ও কার্ডের ডিজাইন
  scripts/
    smoke.mjs             লাইভ টেস্ট
    build-registry-cache.mjs   ক্যাশ বানায়
  PLAN.md                 পরিকল্পনা
  HOST-INTEGRATION.md     হোস্টে যুক্ত করার নির্দেশ
```

## চালানো

```bash
node scripts/smoke.mjs                     # লাইভ যাচাই
node scripts/build-registry-cache.mjs 250  # ক্যাশ রিফ্রেশ
```
