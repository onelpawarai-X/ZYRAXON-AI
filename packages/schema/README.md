# @zyraxon-ai/schema

Official ZYRAXON AI Schema definitions — Effect-TS schemas for the ZYRAXON protocol.

## Install

```bash
npm install @zyraxon-ai/schema
```

## What is this?

This package contains all the Effect-TS schema definitions used across the ZYRAXON AI ecosystem. It defines the data types, event types, session structures, permissions, and other core data models.

## Usage

```typescript
import { Schema } from "@zyraxon-ai/schema"
```
